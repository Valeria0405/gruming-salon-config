# gruming-salon-config
Учебный проект курса «Разработчик 1С: расширенный» (Яндекс Практикум). Конфигурация груминг-салона с нуля: оперативный учёт, бухгалтерия, зарплата, мобильное приложение, бизнес-процессы.

# Конфигурация «Груминг-салон» + мобильное приложение

## Что реализовано

### Оперативный учёт
- Хранение информации об организации, клиентах, поставщиках, договорах
- Учёт товаров, материалов и услуг (номенклатура)
- Сотрудники и должности
- Запись клиентов к мастерам с контролем оплаты и дублей
- Реализация товаров и услуг с автозаполнением цен
- Поступление товаров и материалов с учётом сроков годности
- Контроль отрицательных остатков
- Два рабочих места: администратора салона и руководителя — отображаются на начальной странице

### Финансовый учёт
- Наличные и безналичные денежные средства
- Поступление на расчётный счёт и списание с расчётного счёта
- Расчёт финансового результата (прибыль/убыток)
- Аналитические отчёты по движению денег

### Цены поставщиков
- Регистр для хранения цен поставщиков
- Документ для внесения цен
- Загрузка цен из Excel-таблиц, полученных от поставщиков

### Бухгалтерский учёт
- План видов характеристик, план счетов, регистр бухгалтерии
- Автоматические проводки по всем операциям
- Оборотно-сальдовая ведомость
- Оборотно-сальдовая ведомость по счёту с аналитикой по плану видов характеристик

### Кадровый учёт и зарплата
- График работы сотрудников и графики работы предприятия
- Регистр кадровой информации с окладами
- План видов расчёта и регистр расчёта
- Начисление по окладу, премии, больничный лист
- Отчёт по начислению заработной платы
- Отражение зарплаты в бухгалтерском учёте

### Мобильное приложение
- Стиль соответствует настольной версии
- Справочники Сотрудники и Услуги
- Документ Запись клиента, обработка при старте приложения
- Регистрация и авторизация пользователей
- Интеграция с основной базой: передача документа Запись клиента

### Бизнес-процессы
- Бизнес-процесс «Дорегистрация клиента» — автоматически запускается при регистрации через телефон

### БСП и внешние отчёты
- Внедрены обязательные подсистемы БСП
- Дополнительно подключены: Организации, Префиксация объектов, Валюты, Дополнительные отчёты и обработки
- Внешний отчёт «Исполнение заказов клиентов»

### Дашборды
- Монитор руководителя: показатели деятельности, сводка новостей, актуальные курсы валют

## Ключевые навыки, освоенные в проекте

| Навык | Где применён |
|---|---|
| Внедрение и адаптация БСП | Обязательные подсистемы, Организации, Префиксация, Валюты |
| Проектирование метаданных | Справочники, документы, регистры |
| Оперативный учёт | Контроль остатков, сроки годности, автозаполнение цен |
| Бухгалтерский учёт | План видов характеристик, план счетов, автопроводки, Оборотно-сальдовая ведомость |
| Расчёт зарплаты | План видов расчёта, регистр расчёта, больничный, премии |
| Учёт денежных средств | Наличные, безналичные, кассы, расчётные счета |
| Рабочие места и дашборды | Администратор, руководитель, новости, курсы валют |
| Интеграция с Excel | Загрузка прайс-листов поставщиков |
| Мобильная платформа 1С | Регистрация, авторизация, обмен с основной базой |
| Бизнес-процессы | Автоматический запуск при регистрации клиента |
| Внешние отчёты | Исполнение заказов клиентов |

## Выводы по проекту

- Разработана полноценная учётная система для груминг-салона с нуля
- Освоено внедрение БСП — навык, востребованный в промышленной разработке
- Реализован бухгалтерский учёт с полным набором отчётов
- Спроектирована подсистема расчёта зарплаты
- Настроена интеграция с мобильным приложением и загрузка данных из Excel
- Разработаны бизнес-процессы и рабочие места для разных ролей
